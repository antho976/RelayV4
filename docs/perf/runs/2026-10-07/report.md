## How to read the tables

- **p50 / p95**: wall time of one iteration of the measured region, in process, no socket unless the name says so.
- **cpu**: process CPU time per iteration (user + system, every thread). Above wall means other threads worked; below means the iteration waited.
- **allocs / bytes**: heap allocations and bytes requested per iteration, counted by a global allocator wrapper.
- **syscalls**: from a separate strace pass with fewer iterations; per iteration, every thread, counted between marks around the measured region, so not the iteration's setup or cleanup.
- **Ir**: instructions retired per iteration under callgrind, deterministic. The breakdown is self cost by subsystem.
- **result**: size of the JSON result the op returned, which is what crosses the socket to a client.
- A row whose outcome is an error code measured that refusal path; the note beside the group says why.
