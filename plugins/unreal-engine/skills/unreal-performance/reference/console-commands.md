# Performance console commands and cvars

Only well-established commands are listed. Run them in the in-game/editor console, through
`ue_console {"command": "..."}`, on the command line with `-ExecCmds="cmd1,cmd2"`, or put
cvars in ini files (`[SystemSettings]` in `DefaultEngine.ini`, scalability sections, device
profiles). Before relying on any cvar not listed here, check it exists: type its prefix in
the console and read the autocomplete, or run `help` (opens the full cvar/command list
generated by the running engine). Cvar defaults change between engine versions.

Querying a cvar: type its name without a value (`r.ScreenPercentage`) to print the current
value and where it was set from.

## Stats overlays

| Command | Shows |
|---|---|
| `stat fps` | Frames per second and frame time |
| `stat unit` | Frame, Game, Draw, RHIT, GPU times, memory |
| `stat unitgraph` | `stat unit` plus a timeline graph (spikes = hitches) |
| `stat game` | Game-thread breakdown (tick, world tick time, etc.) |
| `stat gpu` | Per-pass GPU timings |
| `stat scenerendering` | Render-thread scene rendering, mesh draw calls |
| `stat initviews` | Visibility and culling cost, primitives culled |
| `stat rhi` | Draw primitive calls, triangles, render target memory |
| `stat engine` | General engine counters |
| `stat memory` | Memory stats summary |
| `stat streaming` | Texture streaming pool, wanted vs. streamed |
| `stat levels` | Streaming level states |
| `stat anim` | Animation evaluation cost |
| `stat physics` | Physics simulation stats |
| `stat particles` | Cascade particle stats (legacy) |
| `stat niagara` | Niagara system stats |
| `stat ai` | AI stats |
| `stat slate` | Slate/UMG cost |
| `stat audio` | Audio stats |
| `stat net` | Network stats (multiplayer) |
| `stat none` | Hide all stat overlays |
| `stat <GroupName>` | Any declared stats group, including your own `STATGROUP_*` |

## Profiling captures

| Command | Purpose |
|---|---|
| `ProfileGPU` | Capture one frame's GPU passes into the GPU Visualizer (shortcut Ctrl+Shift+Comma) |
| `r.ProfileGPU.ShowUI 0` | Print the ProfileGPU result to the log instead of opening the window |
| `Trace.Start <channels>` | Start an Insights trace at runtime (5.x) |
| `Trace.Stop` | Stop the trace |
| `Trace.Bookmark <name>` | Add a bookmark to the trace timeline |
| `stat dumphitches` | Log a breakdown whenever a frame exceeds the hitch threshold |
| `CsvProfile Start` / `CsvProfile Stop` | CSV profiler capture to `Saved/Profiling/CSV` |
| `memreport` / `memreport -full` | Memory report file in `Saved/Profiling/MemReports` |
| `obj list` | UObject counts and memory by class (`obj list class=Texture2D`) |
| `obj gc` | Force a garbage collection |
| `listtextures` | Loaded textures with size, format, LOD group |
| `dumpticks` | Log all registered tick functions |
| `HighResShot 1920x1080` | Screenshot to `Saved/Screenshots` |

## Command-line flags (launch arguments)

| Flag | Purpose |
|---|---|
| `-trace=default` | Enable the default trace channels at startup |
| `-trace=default,memory` | Also trace memory allocations (only possible from startup) |
| `-trace=default,loadtime,file` | Loading and file I/O |
| `-tracefile=<path>.utrace` | Write the trace to a file |
| `-tracehost=<ip>` | Stream the trace to a machine running Unreal Insights |
| `-statnamedevents` | Emit stat scopes as named trace events (overhead) |
| `-ExecCmds="stat unit,t.MaxFPS 0"` | Run console commands after startup |
| `-game` | Run the project as a standalone game (with the editor binary) |
| `-windowed -ResX=1920 -ResY=1080` | Fixed window size for comparable captures |
| `-benchmark -fps=60` | Fixed-timestep deterministic run (useful with a scripted scenario) |
| `-csvCaptureFrames=<N>` | Capture N frames with the CSV profiler from startup |

## Frame rate, resolution, threads

| Cvar / command | Notes |
|---|---|
| `t.MaxFPS <n>` | Frame cap; `0` = uncapped. Use `0` when profiling |
| `r.VSync 0/1` | VSync on/off |
| `r.ScreenPercentage <n>` | Render resolution percentage (upscaled). Quick GPU-bound test |
| `r.DynamicRes.OperationMode` | Dynamic resolution mode (0 disabled, 1 enabled if requested, 2 always) |
| `r.OneFrameThreadLag 0/1` | Let the render thread lag one frame behind the game thread |

## View modes (viewport)

`viewmode lit`, `viewmode unlit`, `viewmode wireframe`, `viewmode shadercomplexity`,
`viewmode quadoverdraw`, `viewmode lightcomplexity`, `viewmode lightmapdensity`,
`viewmode lodcoloration`, `viewmode stationarylightoverlap`. Nanite and Lumen
visualizations are in the viewport's View Mode menu (Nanite Visualization, Lumen submenus).

Other visual debugging: `freezerendering` (freeze culling, then fly around to see what is
drawn), `show collision`, `show bounds`, `show <flag>` toggles a show flag.

## Scalability

| Command | Notes |
|---|---|
| `scalability <0-3>` | Set all groups (0 Low, 1 Medium, 2 High, 3 Epic) |
| `scalability auto` | Run the hardware benchmark and apply |
| `sg.ViewDistanceQuality <0-4>` | View distance |
| `sg.AntiAliasingQuality <0-4>` | AA |
| `sg.ShadowQuality <0-4>` | Shadows |
| `sg.GlobalIlluminationQuality <0-4>` | GI (Lumen GI settings per level) |
| `sg.ReflectionQuality <0-4>` | Reflections (Lumen reflections per level) |
| `sg.PostProcessQuality <0-4>` | Post processing |
| `sg.TextureQuality <0-4>` | Textures / streaming |
| `sg.EffectsQuality <0-4>` | Effects |
| `sg.FoliageQuality <0-4>` | Foliage density/distance |
| `sg.ShadingQuality <0-4>` | Material/shading quality |
| `sg.ResolutionQuality <n>` | Resolution scale |

4 = Cinematic. Level definitions live in `BaseScalability.ini` / `DefaultScalability.ini`
sections such as `[ShadowQuality@2]`.

## Lumen, Nanite, shadows

| Cvar | Notes |
|---|---|
| `r.Nanite 0/1` | Toggle Nanite rendering (debug comparison only) |
| `r.Nanite.MaxPixelsPerEdge <n>` | Higher = coarser Nanite triangles, cheaper |
| `r.Lumen.DiffuseIndirect.Allow 0/1` | Allow Lumen GI |
| `r.Lumen.Reflections.Allow 0/1` | Allow Lumen reflections |
| `r.Lumen.HardwareRayTracing 0/1` | Use hardware ray tracing for Lumen (project setting too) |
| `r.Lumen.TraceMeshSDFs 0/1` | Software Lumen traces mesh distance fields |
| `r.Lumen.ScreenProbeGather.DownsampleFactor <n>` | Lower-resolution GI probes, cheaper |
| `r.Lumen.Reflections.DownsampleFactor <n>` | Lower-resolution reflections, cheaper |
| `r.Shadow.Virtual.Enable 0/1` | Virtual Shadow Maps on/off |
| `r.Shadow.Virtual.ResolutionLodBiasDirectional <f>` | Higher = lower directional VSM resolution |
| `r.Shadow.Virtual.ResolutionLodBiasLocal <f>` | Same for local lights |
| `r.Shadow.Virtual.Cache 0/1` | VSM caching (keep on; turning off shows invalidation cost) |
| `r.Shadow.MaxResolution <n>` | Max shadow map resolution (non-virtual shadows) |
| `r.Shadow.DistanceScale <f>` | Scales shadow distance |

Global Illumination and Reflection methods are project settings (Project Settings >
Engine > Rendering) and Post Process Volume settings; set them there rather than forcing
cvars in `[SystemSettings]`.

|---|---|
| `r.Streaming.PoolSize <MB>` | Texture streaming pool size |
| `r.Streaming.MipBias <f>` | Bias streamed mips (lower quality, less memory) |

| `r.SkeletalMeshLODBias <n>` | Bias skeletal mesh LODs |

## Garbage collection

| Cvar / command | Notes |
|---|---|
| `gc.TimeBetweenPurgingPendingKillObjects <s>` | Seconds between automatic GC passes |
| `gc.CollectGarbageEveryFrame 0/1` | Stress test for GC bugs (dangling pointers); never ship |
| `gc.AllowIncrementalReachability 0/1` | 5.4+ opt-in incremental reachability; experimental |
| `obj gc` | Force GC now |

| Cvar / command | Notes |
|---|---|
| `dumpticks` | List tick functions |
